ENSEMBLE-MD-002 · ## 概述 · 随机森林与提升法.md
## 概述

集成学习(Ensemble Learning)是机器学习中的重要分支，通过组合多个预测器来提高整体预测性能。随机森林和提升法是基于决策树的两种主要集成方法。在机器学习竞赛中，许多获胜方案都是对简单树算法的改进，Olson等人在2018年的元研究发现，在排除神经网络的13种算法中，提升树和随机森林是最优的两种算法。

在金融领域应用方面，近年来机器学习在投资组合分配问题中的应用急剧增加，包括：
- Ballings等人（2015）
- Patel, Shah, Thakkar和Kotecha（2015a, 2015b）
- Moritz和Zimmermann（2016）
- Krauss, Do和Huck（2017）
- Gu, Kelly和Xiu（2020b）
- Guida和Coqueret（2018a）
- Coqueret和Guida（2020）
- Simonian等人（2019）

其中，Bryzgalova, Pelger和Zhu（2019）的"资产定价树"研究通过简单的树对投资组合进行排序来创建因子。

ENSEMBLE-MD-004 · ### 运行原则 · 随机森林与提升法.md
### 运行原则
决策树旨在将数据集划分为同质的簇，通过迭代地将样本分成组（通常一次分两个），使得每个组在响应变量Y上尽可能同质。
ENSEMBLE-MD-005 · ### 数学构建过程 · 随机森林与提升法.md
### 数学构建过程
给定大小为I的样本$(y_i, x_i)$，回归树寻找最小化两个子簇内$y_i$总变异的分裂点：

$$V_I^{(k)}(c^{(k)}) = \sum_{x_i^{(k)} < c^{(k)}}(y_i - m_I^{k,-}(c^{(k)}))^2 + \sum_{x_i^{(k)} > c^{(k)}}(y_i - m_I^{k,+}(c^{(k)}))^2$$

其中条件均值为：
$$m_I^{k,-}(c^{(k)}) = \frac{1}{\#\{i|x_i^{(k)} < c^{(k)}\}} \sum_{\{x_i^{(k)} < c^{(k)}\}} y_i$$
$$m_I^{k,+}(c^{(k)}) = \frac{1}{\#\{i|x_i^{(k)} > c^{(k)}\}} \sum_{\{x_i^{(k)} > c^{(k)}\}} y_i$$

最优分割选择：
$$c^{k,*} = \underset{c^{(k)}}{\operatorname{argmin}} V_I^{(k)}(c^{(k)})$$
$$k^* = \underset{k}{\operatorname{argmin}} V_I^{(k)}(c^{k,*})$$
ENSEMBLE-MD-006 · ### 修剪准则 · 随机森林与提升法.md
### 修剪准则
为防止过拟合，需要限制树的大小：

1. **最小叶节点大小**: 强制每个终端节点有最小数量的实例
2. **最小分裂大小**: 要求簇具有最小大小才能继续分裂
3. **改进阈值**: 要求分裂带来足够的损失减少
4. **最大深度**: 限制从根到叶子的最大分裂数

ENSEMBLE-MD-011 · ### 原理概述 · 随机森林与提升法.md
### 原理概述
随机森林由Breiman (2001)提出，结合了两种多样化策略：
1. **数据多样化**: 通过自助法(bootstrap)对样本进行有放回重采样
2. **特征多样化**: 每次分裂时随机选择特征子集
ENSEMBLE-MD-012 · ### 算法步骤 · 随机森林与提升法.md
### 算法步骤
1. **自助采样**: 从原始数据中有放回地抽取多个样本集
2. **随机特征选择**: 对每个节点，从所有特征中随机选择子集
3. **树构建**: 在每个自助样本集上构建决策树
4. **聚合预测**: 对所有树的预测进行平均（回归）或投票（分类）

ENSEMBLE-MD-014 · #### 边际函数 (Margin Function) · 随机森林与提升法.md
#### 边际函数 (Margin Function)
对于分类问题，Breiman (2001) 定义的边际函数为：

$$mg = M^{-1} \sum_{m=1}^{M} 1_{\{h_m(\mathbf{x}) = y\}} - \max_{j \neq y} \left( M^{-1} \sum_{m=1}^{M} 1_{\{h_m(\mathbf{x}) = j\}} \right)$$

其中：
- $M$为树的数量
- $h_m$为第$m$棵树的预测
- 左边部分：正确类别的平均投票数
- 右边部分：其他类别的最大平均值
ENSEMBLE-MD-015 · #### 泛化误差界 · 随机森林与提升法.md
#### 泛化误差界
聚合的不准确性被$\bar{\rho}(1-s^2) / s^2$所限制，其中：
- $s$：单个分类器的强度（平均质量）
- $\bar{\rho}$：学习器之间的平均相关性
ENSEMBLE-MD-016 · #### 重要性质 · 随机森林与提升法.md
#### 重要性质
1. **收敛性**: 随着树木数量增长到无穷大，不准确性收敛到有限值
2. **过拟合抗性**: 随机森林不容易过拟合
3. **偏差-方差权衡**: 通过平均减少方差，同时保持偏差较小

ENSEMBLE-MD-024 · ### 基本思想 · 随机森林与提升法.md
### 基本思想
提升法是一种顺序集成方法，通过构建一系列弱学习器来创建强学习器。每个新学习器重点关注前面学习器预测错误的样本。
ENSEMBLE-MD-025 · ### AdaBoost算法 · 随机森林与提升法.md
### AdaBoost算法
ENSEMBLE-MD-026 · #### 基本原理 · 随机森林与提升法.md
#### 基本原理
1. **初始化权重**: 为每个训练样本分配相等权重
2. **迭代训练**: 顺序训练多个弱学习器
3. **权重更新**: 根据预测错误更新样本权重
4. **最终预测**: 加权组合所有弱学习器的预测
ENSEMBLE-MD-027 · #### 数学表达 · 随机森林与提升法.md
#### 数学表达
权重更新规则：
$$w_{i}^{(t+1)} = w_i^{(t)} \exp\left(-\alpha_t y_i h_t(\mathbf{x}_i)\right)$$

其中：
- $w_i^{(t)}$：第$t$轮迭代时样本$i$的权重
- $\alpha_t$：第$t$个学习器的权重
- $h_t(\mathbf{x}_i)$：第$t$个学习器对样本$i$的预测
ENSEMBLE-MD-028 · ### 梯度提升机 (Gradient Boosting) · 随机森林与提升法.md
### 梯度提升机 (Gradient Boosting)
ENSEMBLE-MD-029 · #### 基本原理 · 随机森林与提升法.md
#### 基本原理
梯度提升通过拟合前一轮预测的负梯度（残差）来构建新学习器：

$$F_{m+1}(x) = F_m(x) + \gamma_m h_m(x)$$

其中：
- $F_m(x)$：前$m$轮的集成预测
- $h_m(x)$：第$m$个弱学习器
- $\gamma_m$：学习率
ENSEMBLE-MD-030 · #### 算法步骤 · 随机森林与提升法.md
#### 算法步骤
1. **初始化**: $F_0(x) = \arg\min_{\gamma} \sum_{i=1}^n L(y_i, \gamma)$
2. **迭代**: 对于$m = 1, 2, \ldots, M$：
   - 计算负梯度：$r_{im} = -\left[\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}\right]_{F=F_{m-1}}$
   - 拟合弱学习器：$h_m(x) \approx r_{im}$
   - 计算最优步长：$\gamma_m = \arg\min_{\gamma} \sum_{i=1}^n L(y_i, F_{m-1}(x_i) + \gamma h_m(x_i))$
   - 更新：$F_m(x) = F_{m-1}(x) + \gamma_m h_m(x)$

```python
from sklearn.ensemble import RandomForestRegressor

    n_estimators=40,           # 随机树的数量
    criterion='squared_error', # 分裂质量度量
    min_samples_split=250,     # 终端簇的最小大小
    bootstrap=True,            # 是否有放回抽样
    max_features=30,           # 每棵树的预测变量数
    max_samples=10000          # 每棵树的样本大小
)

# 训练和预测

y_pred = fit_RF.predict(X_test)
mse = mean_squared_error(y_test, y_pred)
```

## 总结

随机森林和提升法作为基于决策树的集成学习方法，在现代机器学习中具有重要地位：

1. **随机森林**: 通过自助采样和特征随机化，提供稳定且易于调优的解决方案
2. **提升法**: 通过顺序构建和错误聚焦，实现更高的预测精度
3. **金融应用**: 在投资组合管理、风险评估、因子投资等领域表现优异
4. **持续发展**: XGBoost、LightGBM等新算法不断推进性能边界

这些方法为数据科学家提供了强大的工具，特别是在处理表格数据时，往往能够达到state-of-the-art的性能水平。
