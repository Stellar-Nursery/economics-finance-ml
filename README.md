# 经济金融机器学习

中山大学岭南学院 · 刘晓彬 副教授

本目录收录 16 份 HTML 课件，按“AI协作方法 → 数据处理实践 → 因子与量化研究 → 机器学习方法与金融应用”组织。主课程包含00—03、04-1—04-5、05-1—05-3；机器学习阶段已发放 ML1 至 ML4。

解压后按包内README运行Notebook；04-4、04-5、05-3、ML1 至 ML4 的交互网页均已提供，可离线打开。课件图片已内嵌；首页课程关系图使用随仓库提供的 `assets/` 文件夹。05-2 ZIP不含输入数据，需将教师另行提供的六张精简Parquet表（约54.7 MB）放入包内 `data/offline/`，再运行Notebook。其他部分材料由教师另行提供。

05-1 使用 Kenneth R. French Data Library 的美国 FF3 与动量月度数据（1927-01—2026-08）；官方原始数据、来源地址与合并脚本随包提供。解压后打开 `05-1-课堂材料`，从 README 开始。05-2《量化投资导论》共 103 页，介绍量化投资的定义、发展历史、策略、A 股市场环境、行业版图、研究流程及案例；配套Notebook保留原内容与运行结果，提供不含数据的独立材料包。

05-3《因子评估、组合回测与机器学习入口》共156页，以EP为主案例，涵盖数据筛选、中性化、IC与ICIR、衰减、分组与回测、组合绩效及机器学习预测得分入口。图示已内嵌，配套Notebook及代码见上方不含数据包。解压后打开 `05-03-课堂材料`，按README将教师另行提供的数据包合并到同名目录，确认32个输入文件位于 `data/offline/`，再运行 `notebooks/05-03-EP因子评估与回测.ipynb`。

ML1《线性模型与惩罚回归》共70页，从EP评分进入个股收益预测，使用EP、动量、波动率和相对成交量共7个中性化信号比较OLS、Ridge、Lasso和Elastic Net。规模与行业仅用于中性化。课件区分训练损失、验证MSE与Rank IC，模型按不含惩罚项的验证MSE选参。

ML1公开包不含月度输入数据及全量逐股预测表；运行前需取得教师另行提供的课堂数据包，合并到“ML1-课堂材料”目录，并确认`data/ep_ml1_panel.parquet`存在。已有Notebook输出和交互示例可直接阅读，数值表与图表保留教学汇总及有限股票示例。

ML4 的课件和交互可直接离线打开。公开包可阅读 Notebook、查看保存的输出并运行模拟实验。完整复跑 19 个代码单元时，将教师提供的课堂数据包解压到同一位置，合并进 `ML4-课堂材料/` 目录，使股票面板位于 `data/ep_ml_panel.parquet`，逐股袋外预测位于 `output/forest-oob.parquet`。
